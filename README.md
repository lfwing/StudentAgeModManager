# StudentAge Mod 管理器

这是《学生时代》的 BepInEx 与 Steam 创意工坊 DLL Mod 管理器。

它可以：

- 从 EXE 内嵌包一键离线安装 BepInEx 和 Workshop Bridge；
- 打开推荐 Mod 的 Steam 工坊页面；
- 显示当前 Steam 用户已订阅的 DLL 工坊项目，包括未收录、私密和已禁用项目；
- 在管理器内启用或禁用工坊 DLL，不取消订阅、不移动 Steam 源文件；
- 识别手动放入 `BepInEx/plugins` 的本地 DLL；
- 启用或禁用本地 DLL，不会直接删除文件；
- 在本地版与工坊版使用相同 `BepInPlugin` GUID 时显示冲突警告。

> 推荐目录只是官方整理的推荐列表，不是加载白名单。未进入推荐目录的工坊 Mod 同样可以正常加载和运行。

## 📥 下载

**[下载 ModManager.exe](https://github.com/white12666/StudentAgeModManager/releases/latest/download/ModManager.exe)**

- 支持 Windows 10 / Windows 11；
- 下载后直接运行，不需要安装；
- BepInEx 与 Workshop Bridge 已包含在 EXE 中，首次安装前置不再访问 GitHub 或第三方镜像；
- 可以放在任意位置，管理器会尝试自动找到游戏目录。

## 🚀 三步开始使用

### 1. 安装前置

1. 完全退出游戏；
2. 运行 `ModManager.exe`；
3. 点击顶部黄色提示中的“**一键安装完整前置**”；
4. 安装完成后点击“**刷新**”，或启动一次游戏。

管理器会直接解压经过固定 SHA-256 校验的内嵌 BepInEx 包，并把 Workshop Bridge 放到：

```text
BepInEx/patchers/StudentAge.WorkshopBridge.dll
```

如果已经安装 BepInEx，按钮会显示为“**安装工坊 Mod 支持**”，只补装或更新 Bridge。

主界面不再要求选择“直连/镜像”。工坊内容始终由 Steam 下载；在线推荐目录会在后台自动
尝试 GitHub 直连与文本镜像，获取失败也不影响本地订阅的发现、启停和加载。

### 2. 安装工坊 DLL Mod

你可以从管理器的推荐目录打开工坊页面，也可以直接打开作者提供的 Steam 链接。

```text
点击“打开工坊页面”
        ↓
在 Steam 中点击订阅
        ↓
等待下载完成
        ↓
游戏关闭时点“刷新”，或下次启动游戏时自动启用
```

“打开工坊页面”会在 Steam 已运行时直接进入客户端中的对应工坊项目；Steam 未运行或
客户端协议调用失败时会回退到官方网页。订阅和取消订阅仍然在 Steam 中完成。

安装 Bridge 后的新订阅，通常会在下载完成后点击“刷新”或下一次游戏启动时自动启用。
安装前已经订阅的项目不会被批量擅自开启；它们会显示在管理器中，可直接点击
“启用”，也可以在游戏“本地”页开启。

### 3. 管理 Mod

- 工坊 Mod：在 Steam 中订阅/取消；在管理器卡片或游戏“本地”页开启/关闭；
- 手动 DLL：在 Mod Manager 中点击“启用”或“禁用”；
- 管理器只允许在游戏关闭时切换，操作后会立即同步工坊状态，下次启动游戏生效；
- 禁用工坊项目不会取消订阅。Steam 仍会下载作者更新，项目保持禁用；重新启用时直接使用最新版。

## 🖥️ 界面状态是什么意思

状态由来源、是否收录和当前启用情况组成。

| 界面状态 | 含义 |
|---|---|
| `Steam 工坊 · 已收录 · 已启用` | 已进入推荐目录，并已在本机启用；只显示一张合并卡片 |
| `Steam 工坊 · 已收录 · 未启用` | 已进入推荐目录，但本机目前没有加载它（尚未订阅，或已被关闭） |
| `Steam 工坊 · 未收录 · 已启用` | 没进推荐目录，但已正常启用，可以正常运行 |
| `Steam 工坊 · … · 下载中` | Steam 尚未完成下载或作者更新，暂时不会加载 |
| `Steam 工坊 · … · 待刷新` | 已在游戏中启用，点“刷新”或启动一次游戏后即可加载 |
| `Steam 工坊 · … · 缺少描述文件 / 文件不完整` | 缺少或不符合 `workshop-plugin.json` 包规范，不会被加载 |
| `Steam 工坊 · … · 重复 GUID` | 与另一个当前加载候选声明了相同插件 GUID，只应保留一个启用 |
| `本地 · 未收录 · 已启用` | 手动安装的本地 DLL，目前位于插件目录 |
| `本地 · 未收录 · 未启用` | 本地 DLL 已被管理器移出插件目录 |
| `本地 · 未收录 · 路径冲突` | 启用区和禁用区同时有同名项目，需要手动处理 |
| `本地 · 未收录 · 重复 GUID` | 与另一个本地或工坊 Mod 使用了相同 GUID |

颜色规则：

- “已收录 / 已启用”为绿色；
- “未启用”为红色；
- “未收录”为中性灰色，只表示不在推荐列表中，不代表有问题；
- 下载中、待刷新、路径冲突和重复 GUID 为橙色。

### “收录”和“启用”不是一回事

- **收录**：是否进入官方推荐列表；
- **启用**：Mod 是否已经连接到 BepInEx，能被游戏加载。

因此，“未收录 · 已启用”是正常状态，不代表 Mod 有问题或无法运行。

## 🔌 本地 DLL 怎么显示

管理器会扫描：

```text
BepInEx/plugins
BepInEx/ModManager/disabled
```

只要 DLL 中有有效的 `BepInPlugin` 声明，就会显示名称、版本和路径。

推荐每个 Mod 使用独立目录：

```text
BepInEx/plugins/MyMod/
├─ MyMod.dll
└─ Dependency.dll
```

点击“禁用”时，整个目录会移动到：

```text
BepInEx/ModManager/disabled/MyMod
```

重新启用时会原样移回。管理器不会提供删除按钮，也不会自动删除你的 DLL。

以前由旧管理器直装的 DLL 与手动复制的 DLL 没有结构区别，现在都会统一显示为本地未收录 Mod。

## 🖱️ Mod 很多时怎么浏览

卡片超出窗口后会出现滚动条。

鼠标停在以下位置时都可以使用上下滚轮：

- 列表空白处；
- Mod 卡片；
- 卡片中的文字；
- 卡片按钮。

底部的投稿提示和运行状态栏是固定区域，不会跟随列表滚动，也不会被卡片覆盖。

## ❓ 常见问题

### 未收录的工坊 Mod 能运行吗？

可以。只要项目已订阅、下载完成、已启用，并且工坊包符合 Bridge 格式，就可以正常运行。

管理器从本地 Steam 订阅数据发现项目，不依赖收录或公开页面。未收录、私密项目即使
当前禁用，只要本地包带有效声明也会继续显示；启用后状态会变为：

```text
Steam 工坊 · 未收录 · 已启用
```

### 已收录的工坊 Mod 为什么显示“未启用”？

如果管理器能读取本机 Steam 状态，会进一步显示“下载中”“待刷新”“缺少描述文件”
或“文件不完整”。显示“未启用”的常见原因包括：

- 尚未在 Steam 中订阅该项目；
- Steam 还没有下载完成，或项目正在更新；
- 属于安装前已有的订阅，尚未在管理器或游戏“本地”页开启；
- 玩家已经手动关闭；
- 工坊包缺少有效声明；
- Bridge 尚未随游戏启动运行，也没有在游戏关闭时点击“刷新”。

### 为什么同一个已收录工坊 Mod 没有显示两次？

管理器会按 Workshop ID 合并推荐目录信息和本地订阅/Bridge 状态：

```text
索引条目 + 本地工坊状态
          ↓
      一张合并卡片
```

没有进入推荐目录、但带有效 DLL 声明的本地订阅仍会显示在前面的“Steam 创意工坊目录”中，
不会因为在线索引暂时不可用而被归入“本地已安装插件”。

### 在管理器或游戏“本地”页关闭后还会自动开启吗？

不会。Bridge 会尊重手动关闭。禁用只会把项目从当前用户的启用列表中移除并停止加载，
不会取消订阅或改动工坊源目录。Steam 仍会照常下载作者更新，但项目保持禁用；以后点“启用”
会直接使用更新后的最新版。取消后重新订阅同一个 Workshop ID，也不会强制再次开启。

### 本地版和工坊版都有，而且 GUID 相同怎么办？

不要同时启用。BepInEx 会把它们视为同一个插件，加载结果可能取决于扫描顺序。管理器会把
两个当前加载候选都标为“重复 GUID”；禁用本地版或工坊版中的任意一个，刷新后警告就会消失。

### 普通 JSON Mod 会被 Bridge 当成 DLL 加载吗？

不会。没有有效 DLL Bridge 声明的普通工坊项目继续由游戏原生 Mod 系统管理。

### 点击按钮后为什么没有自动订阅？

按钮名称是“打开工坊页面”。Steam 已运行时会直接打开客户端中的对应项目，否则打开
Steam 官方网页；请在 Steam 中自行点击订阅或取消订阅。

### 顶部显示“工坊 Mod 支持缺失或需更新”怎么办？

完全退出游戏，然后点击“安装工坊 Mod 支持”。管理器会用内嵌版本修复 Bridge。

### 如何查看加载结果？

检查：

```text
BepInEx/WorkshopBridge.log
BepInEx/ModManager/WorkshopRefresh.log
BepInEx/LogOutput.log
```

### 取消订阅后会留下 DLL 吗？

Steam 负责删除工坊内容。Bridge 会在后续游戏启动时清理对应的加载项，不会复制或删除 Steam 的源目录。

### 杀毒软件为什么可能提示？

管理器会写入 BepInEx 目录，Bridge 会创建目录联接，少数安全软件可能提示。建议从本仓库 Release 下载并核对来源。

## 🔐 使用 DLL Mod 前请注意

DLL Mod 是可执行代码，权限与游戏进程相同。请只安装可信作者发布的项目，并优先查看源码和社区反馈。

管理器和 Bridge 会检查订阅、下载状态、manifest 与路径，但无法替你判断一个 Mod 的功能是否值得信任。

<details>
<summary><strong>想了解 Workshop Bridge 如何工作？</strong></summary>

游戏原生 Mod 系统会记录启用的 Workshop ID，但不会加载 DLL。Workshop Bridge 是 BepInEx Preloader Patcher，会在 BepInEx 扫描插件前运行。

```text
Steam 工坊项目/BepInEx/plugins
                 │
                 └──目录联接──> BepInEx/plugins/.workshop/<WorkshopId>
```

Bridge 只有在以下条件明确时才让 Mod 生效：

- 当前 Steam 用户确实订阅了该项目；
- Steam 已完成下载，项目不在更新中；
- 项目已在游戏原生 `_mod` 中启用，或是首次识别到的新有效订阅；
- 项目根目录有有效的 `workshop-plugin.json`；
- 固定的 `BepInEx/plugins` 目录中至少有一个 DLL。

任何关键状态不明确时，Bridge 会选择本次不加载，而不是猜测。

每个 Steam 用户的现有订阅都会被单独登记。第一次同步时，已有订阅只会被记录，不会全部自动开启；
之后的新有效订阅会在下载完成后点击“刷新”或下一次启动游戏时自动开启。

详细实现见 [DEVELOPMENT.md](DEVELOPMENT.md)。

</details>

<details>
<summary><strong>想了解推荐目录和 Steam 显示资料？</strong></summary>

推荐目录来自仓库中的 `mods.json`。每个条目必须有唯一 `id` 和 Workshop ID。

如果索引没有填写名称或简介，管理器会从 Steam 读取并缓存显示资料；索引中明确填写的非空文字始终优先。

Steam 返回的下载地址、路径和文件名不会被用于安装。管理器只使用标题和说明，并自行根据
规范的数字 ID 构造 Steam 客户端 URI 或官方 HTTPS 工坊页面地址。

缓存位置：

```text
BepInEx/ModManager/workshop-metadata.json
```

</details>
